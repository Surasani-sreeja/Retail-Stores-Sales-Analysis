# Power BI Dashboard Guide

Import `cleaned_retail_sales.csv` into Power BI.

## KPI Cards
- Total Revenue = SUM(Net_Sales)
- Units Sold = SUM(Quantity)
- Average Order Value = AVERAGE(Net_Sales)
- Estimated Profit = SUM(Profit_Est)

## Recommended visuals
1. Line chart — Month vs Net_Sales
2. Bar chart — Product vs Net_Sales
3. Bar chart — Region vs Net_Sales
4. Donut chart — Channel vs Net_Sales
5. Matrix — Category/Product with Revenue and Units Sold
6. Slicers — Date, Region, Category, Channel

Dashboard title: **Retail Store Sales Performance Dashboard**
