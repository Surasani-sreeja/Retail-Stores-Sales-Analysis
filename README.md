# Retail Store Sales Analysis

A Data Analyst portfolio project using **Python, Pandas, SQL, Excel, and Power BI** to analyze retail transactions and generate business insights.

## Objectives
- Analyze revenue and units sold
- Identify monthly sales trends
- Find top-performing products
- Compare regions and sales channels
- Track key KPIs and estimated profit

## Tools
Python, Pandas, NumPy, SQL, Excel, Power BI, Matplotlib

## Files
- `raw_retail_sales.csv` — source sample data
- `cleaned_retail_sales.csv` — analysis-ready data
- `retail_sales_analysis.xlsx` — Excel analysis workbook
- `analysis.py` — Python analysis and charts
- `analysis_queries.sql` — SQL queries
- `POWER_BI_DASHBOARD.md` — Power BI dashboard instructions
- `requirements.txt` — Python dependencies

## Run Python
```bash
pip install -r requirements.txt
python analysis.py
```
